Bienvenido al proyecto Generador de Facturas.

Este proyecto muestra cómo armar una app sencilla en Flask que genera facturas en PDF con flask, flask-sqlalchemy, bootstrap y weasyprint. La forma más común de crear PDFs con Python puro es Reportlab, pero lleva bastante tiempo lograr que el diseño quede como uno quiere. En este proyecto uso weasyprint para generar la factura en PDF a partir de una plantilla HTML.

Puedes probar el generador. Si tienes sugerencias para mejorarlo, escríbeme.
